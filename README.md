# BRMod

Фанатский мод для игры с друзьями (Steam-мультиплеер, 2–4 игрока). **Мод должен стоять у всех игроков в лобби.**

---

Сделан через слопогенераторы (astra x opus)


## Новые патроны (выпадают редко, видны при заряжании)

| Патрон | Как работает |
|---|---|
| **Жёлтый — скрытый** | Выстрелил в соперника — урон получаешь **ты**. Выстрелил в себя — как холостой (ход продолжается). Лупа и телефон показывают его **боевым**. Инвертор делает его боевым. |
| **Розовый — лечащий** | Лечит на 1 заряд того, в кого попал (с ножовкой — на 2), можно выше лимита раунда, но не больше 6. Инвертор делает его боевым. |
| **Чёрный — неизвестный** | При выстреле срабатывает как боевой или холостой с равной вероятностью. Лупа и телефон сообщают только цвет. Инвертор и жёлтая Уно сохраняют тип неизвестным. |

Шансы при подходящей зарядке: по 25% для жёлтого и розового и 18% для чёрного.

## Новые предметы

| Предмет | Как работает |
|---|---|
| **Уно: возврат** (красная) | Смотрит на последний выстрел соперника в тебя. Боевой возвращает тебе потерянные заряды и наносит стрелявшему урон. Холостой отнимает у тебя 1 заряд. Карта недоступна, если последний стрелявший выбыл или у него 1 заряд. |
| **Уно: подмена** (жёлтая) | Используешь в свой ход, карта ложится перед тобой под индикатором здоровья: следующий выстрел соперника в тебя меняет патрон (боевой ↔ холостой). Действует 1 круг — до твоего следующего хода. |
| **Уно +4** | Выбираешь игрока (или себя): до 4 его предметов превращаются в пиво. |
| **Тотем бессмертия** | Пассивный. Если тебя должны убить — остаётся 1 заряд, тотем сгорает с частицами и звуком. Защищает от любого урона (выстрел, скрытый патрон, отражение, таблетки). |
| **Бутылка виски** | На 1 круг (до твоего следующего хода) все предметы на столе срабатывают как случайные. Вид и описание не меняются. |
| **Шот виски** | То же, но только предметы выбранного игрока. |
| **Ядерный гриб** | Уничтожает предметы у всех, включая тебя. Предметы с Бункером выживают. |
| **Дымовуха** | Перемешивает предметы всех игроков между собой (у каждого остаётся столько же предметов). |
| **Грозовая туча** | Выбираешь число 1–6: через столько использований предметов (любыми игроками) патроны в дробовике перемешаются. |
| **Таблетки** | 50%: +2 заряда (можно выше лимита раунда, максимум 6). 50%: −1 заряд (можно умереть). |
| **Доп. стволы** | Следующий выстрел в соперника попадает во **всех** соперников. Нельзя вместе с ножовкой. |
| **Повязка** | До своего хода игрок видит точечные контуры стола, комнаты и своих предметов. При раздаче видны контуры ящика и предмета в руке, а также кнопки свободных ячеек. |
| **Наушники** | Выбранный игрок до своего хода слышит только музыку. |
| **Синяя изолента** | В свой следующий ход игрок не может брать предметы и сразу берёт дробовик. |
| **Пиво** (изменено) | 10% шанс опьянеть: в свой следующий ход нельзя стрелять, пока не выпьешь всё своё пиво (новое пиво тоже может опьянить). Внизу экрана будет подсказка, почему нельзя стрелять (так же при связанных руках). |
| **Adrenaline Zero Sugar** | С шансом 95% выдаёт или обновляет случайное зачарование каждого оставшегося предмета на столе. С шансом 5% уничтожает один случайный предмет. |
| **Банка таблеток** | До твоего следующего хода защищает от глушилки. Блокиратор хода недоступен, если у него нет подходящих целей. |

Пасхалка: у игрока с ником **Sergkomp** сзади виляет хвост.

## Зачарования

При доставании из ящика предмет получает зачарование с шансом 12%. У каждого эффекта свой перелив на поверхности предмета. Название и действие видны в описании при наведении.

- **Бункер** переливается золотым и защищает от ядерного гриба.
- **Дофамин** переливается розово-фиолетовым и защищает от кражи. Обычный адреналин недоступен, если среди предметов соперников нет подходящих для кражи.
- **Кодировка** переливается голубым и сохраняет родную способность предмета под действием виски.

## Автодоставание предметов из ящика

Во время интро и раздачи предметов внизу слева появляется кнопка **«Автодоставание предметов»**, то же самое делает клавиша **G**. При ручном взятии или размещении предмета автоматический режим выключается. Настройка запоминается.

## Установка

1. Версия игры у всех одинаковая (мод сделан под v2.2.0.6).
2. Скопируй папку `BRMod` в папку игры рядом с `Buckshot Roulette.exe`:
   `...\steamapps\common\Buckshot Roulette\Buckshot Roulette_windows\BRMod`
   (Steam → ПКМ по игре → Управление → Просмотреть локальные файлы).
3. Запусти `BRMod\install.bat`.
4. Запусти игру через Steam — в меню рядом с версией появится `+BRMod 2.1.1`.

Игроки без мода или с другой версией мода не смогут зайти в лобби (ошибка несовпадения версий) — так и задумано, иначе у всех будет разная игра. Свой сервер не нужен: «сервер» — тот, кто создал лобби.

## Настройки — `BRMod\config.cfg`

- Для каждого предмета: включён ли, сколько штук на игрока и на весь стол. Действуют настройки **хоста**.
- `[shells]` — шансы особых патронов, `[enchantments]` — шанс зачарования при доставании, `[beer]` — шанс опьянеть.
- `[controls] autograb_key` — клавиша автодоставания.
- Свой звук тотема: положи `BRMod\sounds\custom_totem.wav` (16-бит WAV) — он заменит встроенный.

## Удаление

`BRMod\uninstall.bat` (удаляет `override.cfg` рядом с игрой), потом удали папку `BRMod`.

## Потестить одному: `play_with_bots.bat`

Запускает оффлайн-катку: ты + 3 бота. Боты без мозгов — сами достают предметы и стреляют наугад. Клавиши:

| Клавиша | Действие |
|---|---|
| F5 | дать себе следующий новый предмет (по кругу) |
| F6 | убрать все свои предметы |
| F7 / F8 | патрон в стволе станет жёлтым / розовым |
| F9 | восстановить всем здоровье |
| F10 | особые патроны при следующей перезарядке |
| G | автодоставание предметов (во время раздачи) |

## Для разработки

`config.cfg` → `[debug] offline_test=true` — оффлайн-стол с 4 ботами; `autotest=true` — сценарий проверки всех предметов (результаты `[BRMod][TEST]` в `%APPDATA%\Godot\app_userdata\Buckshot Roulette\logs\godot.log`, скриншоты в `BRMod\shots`).

Аргументы запуска `-- --brmod-regression` запускают офлайн-проверки BRMod и завершают игру по окончании.

## Важно

- Неофициальный мод, только для игры с друзьями. Не выкладывай его публично: в нём есть фрагменты кода игры, а также чужие модели и картинки (хвост, тотем, виски, карты Уно).
- Файлы игры не меняются — всё подключается через `override.cfg`.
- Звуки сгенерированы кодом; процедурные модели (гриб, дымовуха, туча, повязка, наушники, изолента) сделаны кодом мода. Мод написан с помощью ИИ (Claude).
